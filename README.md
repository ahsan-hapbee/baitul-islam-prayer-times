# Baitul Islam Mosque — Prayer Timings 2026

Mobile-first glance view of the official 2026 iqamah chart for **Baitul Islam Mosque**, Maple / Vaughan, Ontario.

- Next prayer and countdown (Eastern Time)
- Today’s timeline
- This week’s five prayer times (the chart changes each Friday)
- Full-year browse

Source: Ahmadiyya Muslim Jama'at Canada, *Salat Timings 2026* (tarbiyat.ca). This is an unofficial convenience view.

## Local

Open `index.html`, or:

```bash
npx --yes serve .
```

## Deploy

- **GitHub Pages** — this repo’s Pages site
- **Vercel** — `npx vercel`
- **Cloudflare Pages** — upload the folder, or `npx wrangler pages deploy .`
